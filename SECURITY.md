# Security reporting

There is no released application or supported product version yet. Never put sensitive security details, real credentials, or confidential files into public issues or pull requests.

Report a suspected vulnerability privately to `security@koxora.app`. The Product Owner has provisioned this mailbox. Its inbound and outbound delivery and its confidentiality have not been tested yet, so treat it as not yet established for sensitive material, and note that this policy promises no response time, no encryption key and no reward. If you receive no acknowledgement, or the matter is urgent, contact the repository owner through an already known private contact, initially without sensitive details, to arrange a secure channel. Do not publish the confidential report in the repository.

Write in English or German. A first message only needs enough to let us reproduce the problem; send proof-of-concept details once a secure channel is agreed.

Before a public pilot, confirm that the mailbox receives and sends, confirm who can read it, name the people responsible for it, agree a handling process, and update this policy with what was actually established. GitHub Private Vulnerability Reporting is a possible later option; this document does not claim it is enabled.
