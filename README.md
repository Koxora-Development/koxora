# Koxora

Open-source platform for diagrams, mindmaps, data visualization and collaboration.

Koxora befindet sich in **Phase 0: Anforderungen und Projektgrundlagen**. Es gibt noch keine lauffähige Anwendung. Das Repository ist derzeit privat; Open Source ist die erklärte Ausrichtung, Lizenz und Veröffentlichung sind noch offen.

## Aktueller Umfang

Dieser Stand enthält Dokumentation und GitHub-Vorlagen. Es gibt keine Installations-, Build- oder Testbefehle für ein Produkt. Technische Vorschläge sind keine bereits freigegebenen Entscheidungen. Phase 1 beginnt erst nach ausdrücklicher Freigabe des Product Owners.
