# Community, templates, and marketplace

**Status: confirmed long-term target; moderation, legal, and payment operation are not authorized.**

## Content

Templates, diagrams, shapes, themes, assets, and optional plugins. Profiles, tags/search, favorites, ratings/reviews, versions, authors, licenses, reports, moderation, and takedown. Public browsing/downloads should work without login; publishing and account management require authentication as appropriate.

## Publishing

Local export → upload → format/security/license validation → isolated preview → moderation → publication → reports/takedown/updates.

Treat all uploads as untrusted and do not assume legal usability or compatibility. Plugins need stricter manifest/signature/isolation checks than static themes. Preserve provenance, redistribution/commercial terms, and license notices. Moderation needs roles, audit logs, appeals, and reporting channels. Monetization requires tax, consumer-law, and platform-compliance review. Localize all platform interface text under the shared language contract; user content retains its own language.

## Cases to test

Corrupt templates, ZIP bombs, remote URLs, license conflicts, malicious metadata, reported assets, and plugin updates before publication. Cloud/marketplace failures must not interrupt local editing.
