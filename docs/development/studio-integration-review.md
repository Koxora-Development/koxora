## One-profile acceptance on CachyOS

Use this integration head's successful **Desktop foundation** Linux artifact (AppImage, not DEB), including its optional `integration/` helper. It is unsigned and not a public release. Close every older Koxora process, back up exports, and start with a disposable Linux user or dedicated absolute XDG config/data/cache directories. Never run with sudo. The native application stores its chosen repository across restarts; do not subsequently open this profile with the independent #53/#54 snapshots that lack #14's bootstrap.

Use the same synthetic archives generated by `node scripts/generate-studio-review-pack.mjs` and the three detailed guides: [storage](desktop-storage.md), [opening](native-opening.md), [navigation](project-element-navigation.md).

1. Launch offline, choose EN or DE and a local project-storage parent. Import `destination.koxora`, `navigation-source.koxora` and the storage samples. Save edits twice, trash one storage sample and export backups.
2. Follow both source links: foreign locked target centers/highlights without editable handles; local target centers/selects. Rename/reorder without breaking UUID targets. Save/reopen and check persisted camera.
3. Open Settings, then send another `.koxora` through Open With. It must remain queued until the settings dialog closes. Migrate to an empty local parent, verify the old workspace clears, close the dialog, and verify the queued file imports into the new repository. Retained projects, previous snapshots, trash and links must survive restart.
4. Register a stable AppImage/wrapper explicitly using `integration/appimage-integration.py`. A wrapper must set the same XDG variables for isolated file-manager tests. Test cold double-click and warm Open With, including Unicode/punctuation and several files. Current drafts save before switching; corrupt input never replaces work. Existing OS defaults remain unchanged unless you explicitly choose one.
5. Follow a missing project target, send an OS open request while the missing-target dialog is present, and confirm it waits until dismissal. Then use the missing/locate pair to verify explicit import recovery. Queued opening and link navigation must not overwrite an unrelated identity.
6. Restart offline, restore the retained original storage explicitly, and verify source data and portable links. Export newer changes before restoring; repositories are not merged. Repeat cancellation/failure cases and EN/DE/keyboard controls. Unregister the helper and retain all projects.

For Firefox use the compiled integration ZIP served on its dedicated localhost port, not `file://`; wait for service-worker installation before offline reload. Test drops and project/element navigation together. Browser builds do not expose native storage settings or promise OS file associations.
